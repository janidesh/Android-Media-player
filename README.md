## 🌌 The Vision
**Janith Ultra** isn't just a media player; it's a piece of **Liquid Acrylic Glass**. Built with the **Apex Gold Engine**, it transforms your local library into a neon-soaked, high-fidelity sanctuary. No more "ugly" interfaces—just pure, blurred elegance.

---

## 🚀 Key Features

### 🎨 Liquid Glass UI
- **Ultra-Blur Surfaces:** High-end frosted glass panels that react to movement.
- **Dynamic Rotator:** An animated sweep-gradient disc that pulses while music plays.
- **Neon Mesh Backgrounds:** Deep purple and cyan gradients that "bleed" through the interface.

### 🎧 Apex Gold Audio Engine
- **Hardware Priority:** Auto-focus logic that ensures audio never starts silent.
- **Morphic Controls:** Floating glass buttons and a smooth-seek progress bar.
- **Smart Categories:** Instant switching between dedicated Audio and Video libraries.

### ⚡ Technical Excellence
- **Zero-Crash Seek:** Optimized buffer management for smooth fast-forwarding.
- **Auto-Equalizer:** Real-time bass and ultra-boost modes based on the device audio session.
- **JDR Direct:** One-tap access to the developer ecosystem at `jdr.kesug.com`.

---

## 🛠️ Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Media Engine:** Media3 / ExoPlayer
* **Animations:** Compose Transition API & Infinite Transition
* **Design Pattern:** State-driven Morphic UI

---

## 📂 Installation
1. Clone the repository.
2. Open in **Android Studio (Hedgehog or newer)**.
3. Sync Gradle and ensure `media3` dependencies are linked.
4. Run on a physical device for the best **Liquid Blur** performance.
